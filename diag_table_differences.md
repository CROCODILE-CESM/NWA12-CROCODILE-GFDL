# Ocean diagnostic-table differences

This comparison covers the ocean component only, BGC/COBALT and sea-ice settings are excluded. 

The `MOM_*` files are compared. For NCAR, I compared the files from NWA12 run without river runoff.
 
The comparison distinguishes diagnostic file streams, their cadence, vertical coordinate, reduction operation, and registered fields. A field listed under a stream is identified by its MOM6 module name, field name, output name, and reduction.

## Diagnostic file streams and cadence

| Diagnostic purpose                              | NWA12-GFDL                                                                          | NWA12-NCAR                                                                             | Source file(s)                                         |
|-------------------------------------------------|-------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------|--------------------------------------------------------|
| Static grid and geometry                        | No time averaging (`-1` months)                                                     | No time averaging (`-1` days)                                                          | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| Native-grid ocean output                        | monthly and annual means                                                            | monthly means                                                                          | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| Native-grid daily/surface output                | Daily means, with minima and maxima for `tos` and `ssh`                             | Daily means, with minima and maxima for `tos`, `sos`, `mlotst`, and `KPP_OBLdepth`     | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| Fixed-depth z-level output                      | Monthly and annual means                                                            | Monthly means                                                                          | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| Density-coordinate output                       | Not configured                                                                      | Monthly means                                                                          | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| 10m (down to 1km) for Oleander                  | Not configured                                                                      | Daily means                                                                            | `diag_table (GFDL)`; `diag_table (NCAR)`               |
| Monthly snapshot stream                         | Three instantaneous monthly fields                                                  | Not configured as a separate stream                                                    | `diag_table (GFDL)`; `diag_table (NCAR)`               |

## Summary of the principal differences

| Topic                            | Difference                                                                                                                                                                                                             |
|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Output organization              | NWA12-GFDL uses named daily, monthly, annual, z-level, and static streams. NWA12-NCAR uses case-specific native, surface, z-level, rho2, `ole`, and static files.                                                      |
| Temporal coverage                | NWA12-GFDL includes annual native and z-level output. NWA12-NCAR uses monthly output and does not configure annual output.                                                                                             |
| Vertical coordinates             | Both configurations provide native and z-level output, but only NWA12-NCAR provides rho2 output.                                                                                                                       |
| Daily output                     | NWA12-GFDL has a dedicated native daily stream. NWA12-NCAR puts the listed daily surface fields in surface output and writes the listed `ocean_model_ole` fields daily.                                                |
| SSH                              | NWA12-GFDL writes `ssh` daily mean/minimum/maximum and monthly/annual means. NWA12-NCAR writes `SSH` in native output and `zos` in surface output, without SSH minimum/maximum registrations.                          |
| Diagnostic scope                 | NWA12-GFDL emphasizes CMIP6/OMIP annual and monthly diagnostics, while NWA12-NCAR adds many model-internal mixing, transport, tendency, surface, and density-coordinate diagnostics.                                   |
